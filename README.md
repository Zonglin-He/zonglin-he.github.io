# Zonglin He

Academic homepage for Zonglin He. [Open the site](https://zonglin-he.github.io/).

The site is static HTML and CSS. Edit `index.html` for the biography, manuscripts, experience, and education. Edit `styles.css` for the layout. Open `index.html` locally to preview changes.

GitHub Pages publishes the root of the `main` branch.

## Hero image

[The concept illustration](assets/grounding-study.webp) was created with the built-in ImageGen tool. The bounding box is drawn in CSS.
